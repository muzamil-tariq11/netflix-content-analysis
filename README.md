# Netflix Content Analysis

Exploratory data analysis of Netflix's Movies and TV Shows catalog using Python and Pandas.

## 📊 About the Project

This project explores Netflix's content library to understand patterns in content type, production countries, and release trends.

## 🛠️ Tools & Skills Used

- **Python** – Data manipulation and analysis
- **Pandas** – Data cleaning, filtering, value counts
- **Matplotlib** – Data visualization (bar charts)
- **Jupyter Notebook** – Interactive analysis

## 🔍 What I Did

- Loaded and explored the Netflix dataset (8,800+ titles)
- Identified and handled missing values (filled text columns with "Unknown", numeric/date columns with 0)
- Analyzed content type distribution (Movies vs TV Shows)
- Identified top content-producing countries
- Analyzed release year trends
- Visualized findings using bar charts

## 📈 Key Insights

- Netflix's catalog has significantly more **Movies (6,131)** than **TV Shows (2,676)**
- The **United States** is the leading content-producing country
- The dataset covers titles released up through **2021**
